### 换 CDN 域名：一条命令，四处全对齐

```bash
# 1) 先体检（只读，看四处当前值）
python Tools/SetWeChatCDN.py --check

# 2) 填域名（把下面 URL 换成你的 COS 默认域名）
python Tools/SetWeChatCDN.py https://<bucket>-<appid>.cos.<region>.myqcloud.com

# 3) 再体检确认四处都变成 https
python Tools/SetWeChatCDN.py --check
```

- 脚本会校验：`https://` 开头、不带路径、不带端口、不带文件名——填错直接拒绝，不会写坏文件。
- 改的是**源头**（三处配置）+ **当前产物**（game.js）。下次团结引擎出包会从源头重建，不会回退。
- 出包后把 `minigame/webgl/` 根目录 3 个 `.br` 文件传到同一个 COS 桶根目录。

## 五、省钱口径（回答「不用买域名」）

- 云开发免费环境：私有读裸链 418、临时签名过期、改所有人可读会转付费 → **路线冻结，不用**。
- 云开发转付费 19.9/月：手动转不可逆，免费名额注销 1 个月后才能重建 → **不推荐**。
- 云开发**静态网站托管**：默认域名公开可读且便宜（0.21 元/GB），但**单文件上限 50MB**，
  本项目 data 包 93MB 传不进去；且免费环境在小程序发布后第 15 天到期 → **不用**。
- **腾讯云 COS 公有读默认域名**（13:08 拍板采用）：腾讯云自有域名、自带 HTTPS、不用买域名、
  不用 ICP 备案，单对象可放 93MB。存储 50GB 免费 6 个月（个人开通自动发放），
  只按量付外网下行约 0.5 元/GB（93MB 约 4.6 分钱/次）→ **采用这个**。
- 小程序备案本身仍强制（10–30 工作日），与域名无关；体验版测试不用等备案。

## 六、COS 开通最短路径（13:08 拍板，5 分钟做完）

> 账号/实名/建桶必须用主人自己的腾讯云账号在控制台做，Agent 无法代登录。
> 用已有腾讯云账号即可（和微信云开发同一个），无需买域名、无需备案。

**1. 建桶**

- 控制台：https://console.cloud.tencent.com/cos/bucket →「创建存储桶」
- 地域：`广州`（ap-guangzhou，离本机近、域名短）
- 名称：仅小写字母/数字/中划线 `[a-z0-9-]`，不能以 `-` 开头或结尾；完整请求域名 ≤60 字符，
  按 APPID `1256138835` + `ap-guangzhou` 算，**桶名最多 19 个字符**（`xiangsumaoxian` = 14，安全）
  → 域名 = `名称-1256138835.cos.ap-guangzhou.myqcloud.com`
  ⚠️ **创建后不能改名、不能改地域**，只能删桶重建（官方《创建存储桶》原文）
- **数据冗余策略：务必改选「单 AZ 存储」**——控制台默认是「多 AZ」，而多 AZ：
  ① 容量费比单 AZ 贵；② 官方明确「目前暂无多 AZ 资源包」，抵不掉 50GB 免费额度；
  ③ 创建页原文写着「**多 AZ 特性 开启后无法关闭**」，选错只能删桶重建。
  这是整个流程里**唯一必须手动改**的默认项
- **访问权限：公有读私有写**（截图已选中，正确；选成私有读会重现 418，公有读写是高危别碰）
  —— 访问权限是**可补救项**，建错了能在「权限管理」里改，不用删桶
- 默认告警：**保持开启**（1 分钟外网下行 >5000MB 告警，防异常刷流量扣费）
- 内容安全：不用开（要另开万象服务）
- 存储桶标签：不用填
- 默认域名那条「存在安全风险，建议配置自定义域名」的黄色提示：不用管，本项目就直接用默认域名

**桶高级功能（第二张图）：全部保持截图现状，一项都别开**

| 项 | 截图现状 | 要不要动 |
|---|---|---|
| 版本控制 | 关 | ❌ 别开——开了会保留多版本，产生额外容量费 |
| 服务端加密 | 不加密 | ❌ 别动——`.br` 包 SDK 本地解压，加密反而添乱 |
| 极智压缩 | 关 | ❌ 别开——要开通万象服务，且 `.br` 已压过无收益 |
| 日志存储 | 关 | ❌ 别开——会产生日志存储费用 |

**2. 拿默认域名**

桶 →「配置管理」→「域名与传输管理」→ 复制**默认域名**，形如：

```
https://<桶名>-<APPID>.cos.ap-guangzhou.myqcloud.com
```

发给 Agent，跑 `python Tools/SetWeChatCDN.py <域名>` 四处一次对齐。

**3. 上传 3 个文件**（桶 →「文件列表」→「上传文件」，保持文件名不变，传到**根目录**）

| 文件 | 大小 | 说明 |
|---|---|---|
| `f914a42b3a7f596e.webgl.data.unityweb.bin.br` | 89,521,610 B | 主数据包（**13:56 移除登录动画后重新出包的最新 MD5**，旧的 `6b14e054...` / `76815af...` 均已作废） |
| `f8bf6c0fadb2651a.webgl.wasm.code.unityweb.wasm.br` | 8,898,242 B | wasm 代码包（MD5 未变） |
| `webgl.wasm.symbols.unityweb.br` | 1,882,304 B | 调试符号，可传可不传 |

⚠️ **不要**给 `.br` 文件设置 `Content-Encoding: br` 响应头——SDK 会在本地自己解压，
重复解压会失败。控制台默认上传即可，不用加任何自定义 Header。

**4. 验证**

浏览器直接打开数据文件完整 URL，看到浏览器开始下载约 85MB 即成功（可立即取消）。

**5. MP 后台配套**

开发管理 → 开发设置 → 服务器域名 → `downloadFile` 合法域名填上面那个默认域名（**只到域名一级**，不带路径/端口）。

**6. 费用护栏（建议顺手做）**

腾讯云费用中心 → 费用预警 → 阈值设 30 元。正常自测几个月都触发不到；一旦触发说明有异常请求。
